## Ce qui est permis sans rien demander

- **Utiliser** Zorton Utilities sur vos propres machines, pour vos propres
  besoins — bidouilleur, membre de club, école, atelier.
- **Étudier** le code source et apprendre de lui.
- **Enrichir la base de connaissance** (`ADN.DAT`) et partager vos fiches
  avec la communauté : les fiches que vous écrivez restent les vôtres, et
  en les soumettant vous acceptez qu'elles soient redistribuées avec la
  base.

## Ce qui demande une entente écrite avec l'auteur

- **Tout usage commercial** : vendre le logiciel, l'inclure dans un produit
  ou un service vendu, s'en servir pour un service payant (par exemple
  l'assurance qualité de cartes destinées à la vente).
- **Redistribuer** le logiciel ou des versions modifiées.

C'est le même esprit que le semi-ouvert qui fait vivre le monde RC2014 :
les concepteurs publient leurs schémas et vendent leurs cartes. Ici, le
code se lit et s'utilise librement chez soi — et l'auteur garde le droit
de vivre de son travail.

Pour une entente : rmurray@photorm.net

## Note sur les données

La base `ADN.DAT` et le registre des ports ont vocation à être un bien
commun de la communauté : leur enrichissement est libre et encouragé. Les
conditions exactes de redistribution de la base seront précisées quand le
programme de contributions sera ouvert; d'ici là, la règle ci-dessus
s'applique.
